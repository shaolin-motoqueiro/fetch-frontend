# front-fetch

Demonstração de requisições HTTP com a API `fetch` no frontend e Express no backend.

## O que faz

- Lista usuários com `GET /usuarios`
- Cadastra usuários com `POST /usuarios`
- Dados mockados em memória (sem banco de dados)

## Estrutura

```
public/     Frontend (HTML, CSS, JS)
server.js   API e servidor estático
```

## Como rodar

```bash
npm install
npm run dev
```

Acesse: http://localhost:3000

## Stack

- Node.js + Express
- JavaScript vanilla (fetch)
